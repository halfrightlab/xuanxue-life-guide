# 怎么分辨真假师父

> 作者的标准很简单：让你一味相信他的、说"别人都是假的只有我是真的"的、自称无所不能或"精通易经"的，都要防。真正正的人，会让你回到自己身上修。


## 这几种话一出口就要警惕

| 话 | 为什么 |
|---|---|
| "我精通易经" | 光道家五术就学不完，谁说精通基本是骗子。[^1] |
| "我什么都能算、什么都能治" | 不要神话任何人；遇到无所不能的大师就该警惕了。[^2] 任何一门学精都很难，"虚病实病都精通"的神仙，按概率你只会遇到骗子。[^3] |
| "别人都是假的，只有我是真的" | 肯定是假的。[^4] |
| "佛法讲空，所以善就是恶" | 偷换概念，就像"我是人、你是人，所以我就是你"。[^4] |
| "连自修都要付费跟我学" | 让你靠外力、连修行都要交钱的，要多谨慎。[^4] |
| "你只要相信我" | 正的人会说"一切以你自己的感知为准"；要你一味相信的，往往是骗子。[^5] |
| "念了这个就能发财" | 用"你能得到什么好处"诱惑你的，是魔披着袈裟讲佛法。[^6] |

## 几个外在的线索

- **证书不算数**：打印一张证几分钱。[^7]
- **光鲜不算数**：骗子往往特别光鲜，这叫光环效应。[^8] 骗子比普通人看起来还真诚，假的比真的更像真的。[^9]
- **免费不算数**：别因为"人家免费、没骗我钱"就认定他说的是真的。[^10]
- **书里的师父不会公开联系方式，也不会主动加人**，网上用书中人物名号看事的都是骗子。[^11]
- **世界富豪榜上没有一个全职占卜大师**；大师真那么神，怎么不去给国足布个局？[^12]

## 最根本的办法：自己正

作者说，关键不在别人正不正，而在自己正不正：心正、不贪，跟着骗子也能学到东西；盲目崇拜，就把对方阴的阳的全收下了。[^13]

- 先相信自己的心：感觉"大师"有点邪气，就是在提醒你。[^14]
- 修为上去了，自然能分辨真假，别依赖外力。[^15]
- 信但不迷：反复怀疑、反复换大师、法事越做越贵，就是痴迷。[^16]
