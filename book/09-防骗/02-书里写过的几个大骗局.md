# 书里写过的几个大骗局

> 作者和读者亲身经历的五个骗局：面粉"仙丹"、灵力大师、广州购物店、7800 元的易学课、E 先生的"借运"。每个都写清楚是怎么一步步进坑的。


## 1. 面粉做的"仙丹"

一位"周师父"后来坦白：他卖的药丸是纯面粉现捏的，卖的是"希望"。

- **为什么能骗下去**：小病死不了，自己会好，就说是仙丹好用；大病医院都放弃了，来买个希望，没人会追究。[^1]
- **教训**：所有被骗的人，都是心存侥幸。[^1]

## 2. "灵力大师"

星辰的同学信了一个用精液"传灵力"的大师。作者拆解他的话术：身体不好、招小人、感情不顺、破财——这几样谁算谁准。[^2]

## 3. 广州旅游购物店

作者亲身经历，一整套流程层层加码：[^3]

1. 先建立信任，送点小礼物。
2. 再讲"交朋友""只送不卖"。
3. "金钱验人心"：用付钱证明真心。
4. 高潮："镇店之宝"有人喊价五百万，老板"不卖只送"，最后只要一个两万八的"祈福红包"。抢到的人打开一看，东西奇丑无比，边角都没磨平。

## 4. 7800 元的易学课（"骗子的祖师爷"）

2020 年疫情期间，一位据说是领导请来的"易学大神"，宣称交 7800 学费就保证学员**三代以内终身不得重大疾病**、学完半年财务自由，口号是"两天让小白成为大师"。[^4]

| 阶段 | 发生了什么 |
|---|---|
| 7800 | 两天只讲了一个九宫格，接着推 49000 的"私人订制"；台上老学员一个接一个分享"孩子成绩提高、业绩翻倍"；大师说"纠结最耗能量"——作者为了"心定"刷了卡。[^5] |
| 49000 | 只讲了命宫，天干地支还写错三个字；又推 2 万的"终身免费旅游式密训"。[^6] |
| "终身免费"复训 | 另收 1490 场地费，"就当给老师包个红包"。[^7] |
| 结果 | 两年收了三万多学员。几百名受害者分组报案，有转账记录和"百分百保证"的录音。[^8] |

**为什么大部分人不敢维权**：上课时把八字交给老师"免费看看"了。[^9]

## 5. E 先生和 F 女士的"借运"

一位读者写了一万多字的亲身经历：刚毕业、运势低，遇到一对"法力无边"的师父，一眼说中他堂哥患过脑部重病，做法事时又恰好电闪雷鸣，于是深信不疑；之后布风水、收徒、为师父掏心掏肺。几个师兄弟陆续出现绝症、横祸、家庭破裂，他自己一周瘦了 20 公斤。[^10]

他自己总结的这类"师父"的共同点：[^10]

1. 展示一点神通，然后要你一味相信他；出了问题都是你的问题，只有他能解决。
2. 前后说法矛盾，不解释或解释不了。
3. 讲道理夹带私货，否认别的权威、只认他；不让手下人出去做事。
4. 搞团体，突出仁爱慈悲，把别人的成就归功于自己，常让人上台分享。
5. 解决不了就说"时机未到""上面不让说"。

最终的判断标准：**你在现实里有没有过得更好。**[^10]
