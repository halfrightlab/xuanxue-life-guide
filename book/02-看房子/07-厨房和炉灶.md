# 厨房和炉灶

> 看厨房要分清四样：厨房整间在哪、灶台在厨房哪、灶口朝哪、做饭的人背靠哪。作者目前的结论是"灶向吉更重要，做饭人背靠吉位更好"；灶该坐吉还是坐凶，他说还没验证清楚。


## 先分清在说哪一样

| 说的是 | 意思 |
|---|---|
| 厨房 | 整间厨房落在全屋的哪一格，比如全屋的西北 |
| 灶台位置 | 灶台在厨房这个"小九宫"的哪一格 |
| 灶向 | 灶口朝哪边。古书里可能指锅下面添柴的口 |
| 做饭的人 | 人面对灶，背后是哪个方向 |

古书用字很省，"灶房、灶位、灶台、灶坐、灶向"常常混着说，作者认为这是各派吵个不停的原因之一。[^1]

## 先看高低，再看五行

厨房属火，是"高能量"。按[高低和水：砂水平衡](04-高低和水：砂水平衡.md)的口诀，放在 1234 的方位能把能量提上来；放在 6789，本来就高，再加火就过了。

- 西北（乾6）和正西（兑7）属金，厨房的火会克金。西北是"财库"，作者说乾6见火是"火烧天门，破财库"。[^2]
- 西北厨房的具体例子见[九宫：家里每个方位管什么](03-九宫：家里每个方位管什么.md)里的"姥爷"一案。

## 灶台的位置：几个实际的顾虑

作者先讲的是看得见的理由：[^1]

- 以前烧柴，灶对着风口，火星会飞出来；
- 现在用煤气，风吹灭火苗容易中毒；
- 就算用电磁炉，门口窗口的风也会把灰尘细菌吹进锅里。
- 所以厨房**不能密不透气**，但灶也**不能在风口上**。
- 灶像人一样，**背后有靠**才好；也要避开横梁和尖角。
- 老话说"门对门，必伤人"，厨房门和大门、卧室门、厕所门的关系也要一起看。

## 灶坐吉还是坐凶：作者没有定论

| 说法 | 意思 | 作者的态度 |
|---|---|---|
| 《阳宅三要》 | 灶是煮饭养命的地方，要放吉位 | 有道理 |
| 《八宅明镜》 | 灶坐凶位能"压"住凶，灶口朝吉位 | 保留，不好验证 |
| 坐吉向吉 | 两边都照顾 | 案例里用过的折中办法 |
| 第507章的暂时结论 | **灶向吉更重要，做饭人背靠吉位更好** | 坐吉坐凶"再慢慢验证" |

书里还原样列过主张"灶压凶位"一派的八句口诀：[^3]

| 灶压在 | 口诀说 |
|---|---|
| 生气位 | 伤财伤子嗣 |
| 天医位 | 久病无良药 |
| 延年位 | 伤人伤婚姻 |
| 伏位 | 无财又无寿 |
| 绝命位 | 长寿又多财 |
| 六煞位 | 人旺财也旺 |
| 祸害位 | 无病无诉讼 |
| 五鬼位 | 无灾亦无盗 |

紧接着作者就说：现在灶坐吉位的、坐凶位的，流产的、慢性病的、离婚的都很多，**根本分辨不出来**。[^3]所以这八句只是一派的说法。

## 君君朋友家改灶

> [!TIP]
> **一步步挪到北边**
>
> 朋友家厨房开东南门（巽4），灶在西北（乾6）、朝东北（艮8），按八星算是"坐祸害、向绝命"。[^4]
>
> 她先挪到正南（离9），想图个吉位，却忘了南边本来能量就高，又正对着门。作者劝她先把灶从南边挪开，先解决血压问题。[^5]
>
> 最后她选了正北（坎1）：一来可以坐吉向吉，二来能提高北边、相当于降低南边。北边背后是窗、没有靠，她打算用比台面高的窗台、带背板的集成灶、加纱网来补。作者说：靠山可以想办法，吉凶位的能量却不好改。[^5]
>
> 后来她说感觉不出原来灶坐凶位有没有"化煞"作用，所以作者也说没法印证。[^4]


## 厨房和厕所

作者说，不光是厨房和厕所同在一格不好，**灶台和水池也不宜挨得太近**：一边做饭一边洗菜洗碗，水汽碰明火，容易出事，古人叫"避开水火冲"。[^6]

- 厨房和厕所就算不在同一格，只要挨着，**灶尽量别装在靠厕所的那面墙上**。
- 已经同宫了怎么办：选房时就避开最好；装修时能改格局就改，比如中间隔出个小厅；改不了，就打扫干净。
- 作者说"凶"主要指健康、破财、官非，风水改不了就从人身上改：讲卫生、多运动；不投机；情绪稳、少管闲事。[^6]
- 有人问能不能放摆件化解，作者笑着说：也可以放个心理安慰。[^7]
