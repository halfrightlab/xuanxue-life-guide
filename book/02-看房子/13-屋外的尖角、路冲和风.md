# 屋外的尖角、路冲和风

> 书里把房子周围对人不利的形状和环境叫"煞"：路直冲着门、两栋楼之间的窄缝、尖角、强反光、带刺的东西……作者说大部分煞"都有直接的道理"。处理顺序是：避开、挡住、转化，最后才是"斗"。


## 大部分煞，都有看得见的道理

作者说："大部分的煞，都是有直接的科学道理的。"[^1]比如：
- 路直冲着房子，刹车失灵就会撞进来；
- 薄片一样的建筑，被风吹起来一片，就是实打实的伤害；
- 房子紧挨着河或高速路，发洪水、出车祸会直接波及。

另一类是"风"：楼缝、墙角、门窗对穿，会形成加强的风，把家里的气吹散。作者说"气藏不住，人就迷糊，就容易破财，也容易出意外"。

## 常见的煞，一张表

| 名字 | 是什么 |
|---|---|
| 天斩煞 | 两栋高楼之间的窄缝正对着自己家 |
| 路冲 | 一条路垂直冲着房子；在房子后面冲，叫"钢刀戳背" |
| 割脚煞 | 很近、和房子平行的河或高速路 |
| 壁刀煞（菜刀煞） | 别人家的墙、竖着的广告牌，垂直对着自己家 |
| 尖角煞 | 屋里屋外有棱角直接对着 |
| 顶心煞 | 正对着电线杆、灯柱、信号塔、烟囱、大树干这类柱子 |
| 刀刃煞 | 薄片一样的建筑对着自己家 |
| 反弓水 | 路或河弯成弓形，房子在弓的**外侧**；在弓的内侧反而好 |
| 穿堂煞 | 门对窗、窗对窗，风直来直去 |
| 横梁煞 | 床或沙发上方有横梁 |
| 光煞 | 强反光、霓虹灯；屋里的大面镜子、亮面装饰也算 |
| 刺煞 | 避雷针、电线、剪刀菜刀、带刺植物（枣树、月季、仙人掌类、虎皮兰等） |
| 电磁煞 | 附近有高压线、变压器、信号塔；三角形的东西叫"火形煞" |

以上都出自第268章。[^1]作者也提醒：各门派叫法不一样，重点是理解具体情况，不要死记名字。

## 尖刺伤眼睛：任何方向都算

南边（离9）主眼睛，但作者说：房子周围如果有尖刺，**不论在哪个方位，都伤眼睛**。小的伤眼，大的还可能伤到血液。[^2]

## 化解的四个办法：避、挡、化、斗

作者说化煞主要有四种方法，按顺序来：[^3]

| 办法 | 意思 | 例子 |
|---|---|---|
| **避** | 能躲开最好，"煞是一把刀" | 横梁压床就**挪床**；带刺的植物**搬出去不养** |
| **挡** | 挡住它 | 光煞用不透光的窗帘遮住；刀具收进抽屉、刀盒 |
| **化** | 改变它的方向 | 穿堂风，中间放屏风或挂珠帘；路冲、楼缝这类风，**照壁**挡风效果最好，懒得弄的话种大叶子的阔叶树也行 |
| **斗** | 对着干 | 书里不提倡 |

还有一句话："气遇风则散，遇水则止。"所以水也能化风。比如南门口有路冲，中间隔着一个池塘，就化解了。但**北边和东边有池塘**，虽然也能挡风，却会把那里的能量拉低，"得不偿失"。[^3]

## 动手之前，记住三点

作者说化煞要切记三点：[^3]

1. **挑日子**：选吉日动；煞位用"偷修日"（意思是神煞休息、不在岗位，抓紧时间偷偷改）。
2. **别顾头不顾腚**：调这里时，要考虑整体的能量平衡。
3. **以人为本**：人身体不舒服，说明有考虑不周的地方，尽快调整。

有人嫌麻烦，问有没有更简单的办法。作者笑着说："不想努力，还想考个好成绩？"非要省事，就是"花钱买一份小抄"——请八卦镜、五帝钱、葫芦这类法器。[^3]这是他半开玩笑的话，后面他对五帝钱明确不推荐了，见[字画和摆件](10-字画和摆件.md)。

## 风煞：先确认风从哪来

星辰床头漏风的例子（作者查了半天，最后是空调管线密封胶处的一条小缝），见[风水管什么，不管什么](01-风水管什么，不管什么.md)。

## 镜子：不是招邪，是吓人

作者说镜子禁忌多，**不是因为招邪**，而是反光容易形成光煞：大镜子里晃过的影子会让人一惊。[^4]有的门派用镜子"反射"化煞，作者提醒镜子长期对着人也不好。[^5]

## 别忘了现实的危险

外露的钉子、可能掉下来的东西、漏电、噪音、臭味，这些先按现实安全处理，不用等挑日子，也不能靠摆件代替维修。
