# 眉毛怎么看

> 作者的口诀：长、清、弯、黑、亮为好，短、粗、薄、散、乱为差。再看毛往哪个方向长、眉尾指向哪里、眉心宽不宽。眉毛不是定死的：转念、放松眉头的肌肉，眉形和悬针纹都会变。


## 总口诀

**长、清、弯、黑、亮为优；短、粗、薄、散、乱为差。**[^1]

清淡、根根见肉、顺直秀丽的眉毛，灵感强、运势好，多是"智力型"；浓眉大眼不一定好。[^2]

## 逐项看

| 看什么 | 书里的说法 |
|---|---|
| **毛的方向** | 向上竖着长：果敢上进、有阳刚气；向下垂：依赖性强、不自信，眉毛往下长的人容易抑郁；逆着长（不是从眉头顺到眉尾）：贪心自私、脾气暴[^3] |
| **长短** | 偏短或半截眉：偏感性、脆弱易受伤；偏长：理智[^1] |
| **粗细** | 细的敏感，粗的相反；粗壮的多是"武官"型，性急胆大[^4] |
| **浓淡** | 浓眉运势好、得师长偏爱；但黑得发亮、过浓的，私心重[^1] |
| **又粗又黑又长** | 冷酷[^4] |
| **又宽又黑又短** | 胆大有魄力[^1] |
| **剑眉**（直、尾巴带尖） | 直指太阳穴（夫妻宫），影响夫妻感情，女人会比较强势[^5] |
| **纹成一根线的细长眉** | 夫妻运差、人缘一般[^1] |
| **八字眉** | 性格不强势、异性缘好、容易为情所扰；眉尾和眼角都往下垂（"四尾下垂"）更明显[^6] |
| **两眉间距宽** | "眉头阔，大快活"：心大、少生气、乐天，但感情上心也大[^7] |
| **悬针纹**（眉间一道竖纹） | 性格刚硬、肝火旺[^8] |
| **印堂的痣** | 好看、桃花旺，但感情容易重叠，对财运也不利[^9] |

## 眉心：最好常打开

两眉之间是祖窍（上丹田）。常皱眉，负面能量就聚在这里，人会"不开窍"；笑的时候眉心是打开的，所以爱笑的人运气好。[^10]

## 眉毛会变

- **相由心生**：一位剑眉的师姐转念之后，眉毛都弯了一些。[^11]
- **悬针纹、川字纹**：经常给印堂和眉毛"擀皮"，都能变浅。[^12] 具体手法：[^13]
  1. 在眉头附近找肌肉很厚、紧绷的地方，把皮捏起来，放松里面的肌肉，连续几分钟。
  2. 顺着眉毛从眉头到眉尾，用捏脊的手法擀皮。
  3. 用眼保健操刮眼眶的手势，食指稍用力刮眉毛，刮的是里面的肌肉。
  最重要的还是少发怒、少多虑，让放松的速度快过产生新淤堵的速度。
- **掉眉毛**：肺主皮毛，先捏手臂上的肺经看通不通；通的话，就练金刚功或大礼拜调全身。[^14]
