# 咳嗽怎么办

> 书里讲咳嗽的办法散在十几章：先分清是哪种咳，再从吃的、按的、念的、家里的方位四个方向下手。下面把每个办法的做法、用量都写清楚了，书里没写用量的也直说。


作者的思路：咳嗽是肺的事，肺属金，对应白色，所以止咳的偏方大多用白色的东西。[^1] 但比偏方更要紧的是**先离开伤你的东西**——丘书妍在泰国被空气污染呛得一直咳，离开污染源后很快就好了。[^1]

> [!NOTE]
> 咳了很久不好、发高烧、喘不上气、咳血，先去医院。下面的办法是书里的家常做法，作者自己也说要客观验证。


## 先分清是哪种咳

| 表现 | 书里推荐 |
|---|---|
| 带黄痰、嗓子干、小便黄（热咳） | 连皮香蕉冰糖汤 |
| 干咳没痰、口鼻干（肺燥） | 冰糖隔水炖香蕉 |
| 有痰，但不能吃甜的 | 枇杷叶煮水 |
| 普通咳嗽 | 大蒜冰糖水、按大鱼际、象数 820 |
| 家里九宫看不出问题，却一直咳 | 可能是那一年的大运，2024 年别动正西 |

## 吃的

| 名字 | 治什么 | 怎么做、用多少 |
|---|---|---|
| **连皮香蕉冰糖汤** | 热咳：黄痰、嗓子干、小便黄 | 香蕉**带皮**切段，加水和少许冰糖煮成汤。**饭前空腹**喝汤、吃香蕉肉，皮也可以吃。早晚各一次，一般吃两三根就好。[^2] |
| **冰糖炖香蕉** | 咳了很久；干咳没痰、口鼻干 | 久咳：香蕉 1～2 根加冰糖炖，每天 1～2 次，连吃几天，可连皮吃。干咳：3 根香蕉去皮切段，加冰糖和一碗清水，**隔水炖一小时**，连渣吃。[^3] |
| **枇杷叶煮水** | 有痰，又不能吃甜的 | 枇杷叶煮水喝。老叶子大，一天一片就够；对症的话一片就能感觉痰少了，普通咳嗽几片叶子就好。[^3] |
| **大蒜冰糖水** | 咳嗽 | 七八瓣大蒜拍碎，加水煮开，放冰糖，放凉一点再喝。作者说白糖好像也行，让大家自己验证。[^4] |
| **鸡蛋茶加白糖** | 止咳化痰 | 鸡蛋打散，用滚开的水冲开，加几滴香油，再加白糖。[^5] |
| 香油煎姜丝鸡蛋 | 咳嗽 | 用香油煎姜丝鸡蛋吃。书里只提了名字，没写更细的做法。[^6] |
| 其他白色食物 | 养肺止咳 | 葱白带须煮水、白糖拌白萝卜丝、冰糖雪梨水、川贝母炖梨。**书里只列了名字，没写用量。**[^1] |

香蕉性寒，脾胃虚寒、容易拉肚子的人少吃，其他忌口见[香蕉偏方](20-香蕉偏方.md)。

## 按的、写的、念的

**揉大鱼际**：大拇指根部那块肉叫大鱼际。心肺弱的人这里会有痛点，按揉它，有痛点就尽量揉开。力度看对方受不受得了，一点点加。[^4]



![大鱼际：大拇指根部的那块肉](../../images/改命记实录/ch0014.jpg)
*大鱼际：大拇指根部的那块肉*


**祝由：虚写"尚食江"**：食指和中指并拢伸直（剑指），对着胸口和喉咙，在空中写"尚食江"三个字，7 遍一组，哪里痒就对着哪里写。适合感冒或空气不好引起的咳嗽、喉咙痒。[^7]



![剑指虚写"尚食江"](../../images/改命记实录/ch0173.jpg)
*剑指虚写"尚食江"*


**祝由化水**：咳得厉害时，接一杯水，用剑指对着水杯虚写一个"其"字，外面套三个开口的圈，然后把水喝掉。[^7]

**象数**：最简单的是默念 **820**（作者说它健脾益气、化痰利肺）。[^8] 按症状细分的还有很多组，比如小孩咳嗽 200·60、咳了一个月 40·20、肺热黄痰 050·020 或 200·60，全部见[象数速查：头面五官、皮肤和日常](32-象数速查：头面五官、皮肤和日常.md)。

## 家里和心里

- **一直咳，家里又查不出问题**：作者说可能是那一年的大运。2024 年五黄在正西，正西又管肺，所以那一年尽量别动大太极和各个房间正西的东西。[^9]
- **兑7被克**：正西（兑7）属金管肺，那里放了火性的东西（炉灶、大红色），容易伤肺。[^10]
- **脾气**：书里的性情疗法说，"恼伤肺"；孩子总咳，要看看妈妈和老人之间是不是有不开心。见[性情疗法：病和脾气对照表](40-性情疗法：病和脾气对照表.md)。[^11]
