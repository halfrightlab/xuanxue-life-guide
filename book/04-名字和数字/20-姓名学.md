# 姓名学

> 作者对名字的态度：小孩起名尽量避开禁忌，大人没有特殊原因别随便改名——花几百块改个名就想改命，不如把钱拿去读书。起名先看字义有没有"道"，再看偏旁字形、读音、笔画，最后对照喜用神和属相。


## 先说态度

- 名字像衣服：一看布料做工（名字本身好不好），二看合不合身（跟命理配不配）。[^1]
- 名字定了尽量别改来改去；很多"姓名学老师"就是为了卖你一个新名字。有人花 9800 买了个"魏笙今"，三才五格打九十多分。[^1]
- 伟人的名字打分都不高，不用被分数困扰。[^2]
- 姓名学性价比不高；花几百块改名想改命，不如把钱省下来读书。[^3]
- 例外：谐音让孩子抬不起头这类大问题，可以改。[^4]

## 起名的顺序

### 1. 字义：先看"大义"

起名先顺应天道、尊道贵德，再谈五行。书里的例子：刘德华原名刘福荣，"福荣"是向内求的私欲（阴），"德华"是向外的德行（阳）。[^5]

### 2. 避开禁忌

| 禁忌 | 例子 |
|---|---|
| 字义消极 | 灾、厄[^6] |
| 字形藏刀 | "忍"是心上一把刀；"超"拆开是走、刀、口，容易受伤[^6] |
| 太大的字（过阳，担不住） | 圣、帝、天、霸、昊、宇，以及祖先长辈、圣贤、皇帝的名字[^1] |
| 不吉的字（过阴） | 影、梦、波、乐、鑫、笑、器、婵、丹、云[^1] |
| 字形不平衡 | 全是横、全是竖、全是框（如"闫闯阁"）[^1] |

### 3. 偏旁和字形

笔画也有五行：点为水，竖为木，横为土，撇为火，钩（提、捺）为金。名字从上到下（姓、第二字、第三字）大致对应早年/长辈、中年/平辈、晚年/晚辈。[^7]

| 偏旁、字形 | 书里的说法 |
|---|---|
| 草字头 | 脑子灵活，但容易三心二意 |
| 带手 | 有手艺 |
| 带脚 | 爱动，婚姻或工作容易变 |
| 带口 | 容易犯口舌，也利于靠嘴吃饭的职业 |
| 带"王、君、令" | 掌控欲强 |
| 品字形（晶、鑫、磊） | 不利合伙 |
| 女孩名字里水太多 | 容易体寒，对妇科不好 |

[^7]

### 4. 读音

按发音最用力的部位分五行：唇音（b p m f w）属土；舌音（d t n l）属火；喉音（g k h）属水；齿音（z c s zh ch sh r）属金；牙音（j q x y）属木。普通话、方言、古音不同，五行也会变。[^8]

### 5. 笔画

笔画五行有河图数、天干数两套，分歧很大（比如"水""木""火"都是 4 画），作者建议顺便兼顾，不作主要依据。[^5] 姓名学里有些偏旁按特殊笔画算：氵算 4，扌算 4，忄算 4，月字旁算 6，辶算 7，艹算 6 或 9。[^5]

网上常见的"三才五格"是日本人熊崎健翁发明的，可以兼顾参考。[^9]

### 6. 对照喜用神和属相

- **补五行不是缺什么补什么**，而是看喜用神：强的要制、要泄，弱的才补。[^9]
- 字的五行有争议时，按"字义 → 偏旁 → 字形 → 笔画 → 读音"的顺序取；模棱两可的字可以不用。[^9]
- **属相**：避开刑冲克害，用三合三会。例：属鼠宜用申、辰的字形；子午相冲，不用马字旁；子未相害，避"羊"；子卯相刑，避"卯""柳"。[^9]

真想起个好名字要花个把月。"人的名儿，树的影儿"——最终是把树调好，影子自然就好。[^1]
