# 八字入门：从一个字开始

> 作者说学八字可以从一个字开始：先看日干（出生那天的天干）知道自己的本性，再看月令（出生月份的地支）知道哪些年份顺，最后知道自己的喜用神，穿衣、方向、行业都能用上。


## 八字是什么

出生的年、月、日、时，每一项用一个天干加一个地支表示，一共八个字，叫"四柱八字"。[^1]

作者对八字的态度：它像人生地图、像"起手牌"，能告诉你哪里有弯有坑，但不能断定你一定掉进去；同年同月同日生的人命运照样不同。号称什么都能算准的，当神话故事听。[^2]

## 怎么排

网上搜"八字在线排盘"就行。节气交接前后，有的网站会算错，作者推荐"问真八字"免费版。[^1]

## 第一个字：日干，看本性

找到出生那天那一柱的**天干**（也叫日元），它代表你自己。[^3]

| 日干 | 像什么 | 性格 |
|---|---|---|
| 甲（阳木） | 直直向上的大树 | 耿直、要强、不占便宜也不求人、硬气、容易得罪人 |
| 乙（阴木） | 盘旋向上的藤蔓 | 外柔内固执、能随机应变、善用人脉、心软 |
| 丙（阳火） | 太阳 | 热情慷慨、乐观；性急、没心机、缺耐心 |
| 丁（阴火） | 星星、蜡烛 | 外柔内热、有上进心；敏感多疑、慢热；灵性强 |
| 戊（阳土） | 山石、容器 | 包容厚重、重诚信、靠谱；不善变通 |
| 己（阴土） | 田土、管道 | 大度、外柔内固执、心里多疑 |
| 庚（阳金） | 刀剑 | 刚硬倔强、好面子、讲义气、闲不住 |
| 辛（阴金） | 首饰 | 儒雅细腻、有韧性、自尊心强、经不起打击 |
| 壬（阳水） | 江河 | 有冲劲、爱自由、变通强、野心大 |
| 癸（阴水） | 雨露、杯中水 | 温柔、能屈能伸、心思细 |

阳干（甲丙戊庚壬）的人主动、直接、急；阴干（乙丁己辛癸）的人沉得住气、想得多、容易生闷气。[^3]

这只是本性，不是贴标签：知道了长处短处，才知道从哪里改。修行的人会改变，八字就看不准了。[^4]

## 第二个字：月令，看哪些年份顺

出生月份的地支叫**月令**，力量最大。简便看法是"损有余"：能克月令五行的年份、月份，一般比较顺。[^5]

| 出生在 | 月令五行旺 | 比较顺的时候 |
|---|---|---|
| 春天（寅卯月） | 木 | 金年、秋天 |
| 夏天（巳午月） | 火 | 水年、冬天 |
| 秋天（申酉月） | 金 | 火年、夏天 |
| 冬天（亥子月） | 水 | 土年、季末 |
| 季末（辰未戌丑月） | 土 | 木年、春天 |

作者自己秋天出生，金旺，2013 到 2015 年（巳午未，火年）最顺。这个办法只适合大部分普通八字，特殊格局不按这个算；要拿自己过去最顺和最不顺的年份对照验证。[^5]

## 喜用神：日常怎么用

对大多数人来说，克月令的那个五行就是喜用神，和月令同类的是忌神。[^6]

- **查**：也可以网上搜"喜用神查询"，多比较几个网站，一致就用，不一致就自己验证。[^7]
- **用**：方便的时候，物品材质、衣服颜色、行业、去哪个方向的城市，选喜用的五行，避开忌神。[^6]
- **床头朝向**：喜火朝南或东；喜水朝北或西；喜木朝东或北；喜金朝西。[^8]
- 不用追求极致，自己感觉舒服最重要。[^6]

## 顺带：看自己有没有财库

1. 看日干的五行，它克的五行就是你的**财星**（金克木、木克土、土克水、水克火、火克金）。
2. 财星五行的"库"：水库是辰、木库是未、火库是戌、金库是丑。八字里有这个字，就是有财库。[^9]
