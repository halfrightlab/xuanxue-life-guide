# 脚气和手脚干裂

> 作者自己最常用的是香蕉皮内侧擦一擦，几秒钟的事；灰指甲用醋精或紫皮大蒜。下面写清楚每个办法怎么用。


## 脚气（脚趾缝起皮、痒）

| 办法 | 怎么做 |
|---|---|
| **香蕉皮内侧擦** | 用香蕉皮的内侧（白色那面）直接擦患处。作者说一般擦一两次就很明显。[^1] 他自己忙的时候就顺手擦一下，几秒钟的事。[^2] |
| 香蕉皮煮水洗 | 新鲜香蕉皮在痒的地方反复擦，或者用香蕉皮煮水洗，连续几天。[^3] |
| 象数 | 作者第一次是睡前念读者留言里的脚气象数，念着念着睡着了，醒来就好了。**但书里这一章没写出具体数字。**[^2] |
| 无花果汁 | 第807章说"前面说了无花果汁等办法，有效，但各有利弊"。**本站没在正文里找到具体做法**，可能在原书的评论或截图里。[^1] |

作者还说，他自己的脚气不太像真菌感染，更像排毒（总在右脚掌同一个地方起小痘）。师父说是经络不通、一般是寒湿引起的，**疏通经络、练功**效果更好。[^2]

## 冬天手脚干裂、冻裂

| 办法 | 怎么做 |
|---|---|
| 香蕉皮内面擦 | 用香蕉皮的**内面**擦裂口，连擦几天。[^4] |
| 香蕉皮贴敷 | 把香蕉皮贴在裂口上。[^3] |

## 灰指甲

| 办法 | 怎么做 |
|---|---|
| **醋精** | 把醋精涂在灰指甲表面和蜂窝状的小孔里，每天涂几次，一直涂到长出新指甲。[^5] |
| **紫皮大蒜片** | 紫皮大蒜切片，贴在指甲上。几天后如果稍微有点疼，说明新指甲要长出来了。[^5] |

作者解释：醋精和大蒜都能抗真菌。[^5]
