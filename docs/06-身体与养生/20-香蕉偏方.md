# 香蕉偏方

> 第827章整章讲香蕉：作者从《岭南采药录》《本草纲目拾遗》等书里摘了 27 条用法、5 个食疗做法和 9 条注意事项。下面按"治什么、怎么用"重新排好，另外补上书里别处讲到的 3 个香蕉用法。


香蕉性寒，作者说平时不建议多吃；但当药膳用，作用很多，香蕉根、香蕉皮尤其有用。[^1] 下面每一条都照书里的写法：用香蕉的哪一部分、怎么做、用多少、多久。书里注明了出处的，括号里写上。

> [!NOTE]
> 第23、24条讲的是乙型脑炎和艾滋病，这是急重病，书里只是摘录资料，不能代替治疗。第2条作者自己也写了：正在住院或吃药的人慎用，以免冲突。


## 作者自己常用的三个

这三条是作者在别的章节里亲口推荐、自己用过的，比第827章的摘录更具体。

| 治什么 | 怎么用 |
|---|---|
| **咳嗽**（带黄痰、嗓子干、小便黄） | 香蕉**带皮**切段，加水、加少许冰糖煮。**饭前空腹**喝汤、吃香蕉肉（皮也可以吃）。早晚各一次，一般吃两三根就好。[^2] |
| **脚气**（脚趾缝起皮、痒）、**冬天脚后跟干裂** | 用香蕉皮的**内侧**擦患处。一般擦一两次就明显。[^3] 作者说自己忙的时候就这样顺手擦一下，几秒钟的事。[^4] |
| 不能吃甜的人咳嗽 | 不用香蕉，改用**枇杷叶煮水**：老叶子大，一天一片就够；对症的话一片就能感觉痰少，普通咳嗽几片就好。[^1] |

## 第827章的 27 条，按毛病分

### 咳嗽、肺燥

| 治什么 | 怎么用 |
|---|---|
| 咳嗽很久不好 | 香蕉 1～2 根，加冰糖一起吃，每天 1～2 次，连吃几天。可以连皮吃。（第13条） |
| 肺燥、干咳没痰、口鼻干 | 3 根香蕉去皮切段，加冰糖和一碗清水，**隔水炖一小时**，连渣一起吃下。（第16条） |
| 止渴、润肺、解酒 | 吃香蕉。书里说脾火旺的人吃了反而能止泻止痢。（第5条，《本草求原》） |

### 痔疮、便血、便秘

| 治什么 | 怎么用 |
|---|---|
| **痔疮、大便后出血** | 香蕉 **2 根，不剥皮**，炖热，**连皮一起吃**。（第1条，《岭南采药录》） |
| 痔疮、便血 | 2 根香蕉**连皮放在火上烤**，趁热吃。（第14条） |
| 痔疮出血、大便干结 | 每天**早上空腹**吃香蕉 1～2 根。（第11条） |

### 血压、胆固醇

| 治什么 | 怎么用 |
|---|---|
| 高血压 | 香蕉皮或**香蕉果柄**（连着果串的那段梗）30～60 克，煮水喝。香蕉花煮水喝，书里说能防脑溢血、中风。**正在住院或吃药的人慎用。**（第2条） |
| 原发性高血压 | 玉米须、西瓜皮、香蕉一起煮水喝。（第10条，《四川中药志》） |
| 胆固醇高 | 香蕉果柄 50 克，洗净切片，开水冲泡当茶喝，连喝 10～20 天。**果柄不能用太多，否则会拉肚子。**（第17条） |

### 牙、耳朵

| 治什么 | 怎么用 |
|---|---|
| 牙痛 | 香蕉 2 根，煮出一碗热汁，**含在嘴里漱**。（第4条，《经验方》） |
| 中耳炎 | 用香蕉茎挤出的汁**滴耳朵**。（第3条） |

### 皮肤

| 治什么 | 怎么用 |
|---|---|
| 手脚皮肤裂口 | 把香蕉皮贴敷在裂口上。（第7条） |
| 冬天冻得手脚皲裂 | 用香蕉皮**内面**擦患处，连擦几天。（第15条） |
| 皮肤痒、脚气 | 新鲜香蕉皮在痒的地方反复擦；或者用香蕉皮煮水洗，连续几天。（第18条；第8条说香蕉皮里有抑制真菌的成分） |
| 蚊子叮、虫咬 | 香蕉皮内面轻轻擦，消肿。（第25条） |
| 长痘（痤疮）、雀斑 | 香蕉半根捣成泥，加点牛奶调成糊，敷脸 10～15 分钟后洗掉。（第9条） |
| 痈肿、疔疮（红肿化脓的疙瘩） | 新鲜香蕉根茎或叶子捣烂挤汁，涂在患处。（第12条） |
| 热疖肿毒 | 新鲜香蕉根捣烂，敷在患处。（第22条，《新医疗法与中草药选编》） |

### 其他

| 治什么 | 怎么用 |
|---|---|
| 肾结石 | 香蕉根煮水喝，利尿排石。用五六把（原文叫“香蕉把”），喝半个月，每天两大碗，早晚各一碗。（第27条，《中华本草》） |
| 痛经 | 每晚睡前喝一杯热牛奶，加香蕉和一勺蜂蜜。（第21条） |
| 早上没精神 | 早饭后、午饭前吃一点香蕉，保持血糖。（第19条） |
| 紧张 | 香蕉维生素 B 多，帮助放松神经。（第26条） |
| 心绞痛 | 书里只写"香蕉有天然的制酸性，有镇痛作用"，没写怎么用。（第20条） |
| 流行性乙型脑炎 | 新鲜香蕉根去皮洗净，捣烂挤汁，每天 1000～1500 毫升，分多次喝，每次少量，以喝了不吐为准，可加点蜂蜜。一般 3～4 天体温开始下降，稳定在 37.5℃ 左右后逐步减量，症状基本消失后停。（第23条）**这是急重病，必须先送医院。** |
| 艾滋病 | 书里只是转述一项国外研究：香蕉里的"香蕉凝集素"可能阻止病毒进入人体。没有用法。（第24条） |
| 麻风 | 古书说两广一带种香蕉树在院子里，一年后"毒尽入树"。只是古代记载。（第6条，《本草纲目拾遗》） |

## 5 个食疗做法

| 名字 | 适合谁 | 做法 |
|---|---|---|
| 香蕉米羹 | 夏天给宝宝吃 | 香蕉 2 根、大米 30 克、白糖适量。香蕉去皮切成指甲大的片。大米煮开后转小火煮熟，放入香蕉片和白糖。 |
| 翠皮香蕉 | 高血压引起的头昏头痛、耳鸣眼花 | 香蕉 600 克、玉米须 50 克、西瓜皮 500 克、白糖 200 克、山楂 20 克。① 香蕉去皮切厚片，加白糖 100 克，用湿棉纸封住碗口，上锅蒸半小时。② 西瓜皮切块，和玉米须、山楂一起煮 20 分钟取汁 100 毫升；再煮一次，一共收 200 毫升，用纱布过滤。③ 把蒸香蕉的汁和西瓜皮汁倒进锅里，加白糖 100 克收汁，浇在香蕉上。 |
| 香蕉奶味粥 | 7 个月以上的宝宝，防便秘、适应辅食 | 奶粉 4 勺、大米烂粥 1 碗、香蕉 1 根、葡萄干 10 克。葡萄干切碎；奶粉倒进粥里搅匀；香蕉捣成泥加进去；撒上葡萄干碎。 |
| 香蕉面膜一 | 护肤 | 香蕉 1 根、牛奶 2 勺、凉浓茶 3 勺，捣烂调成糊。洗干净脸后敷上，15 分钟后温水洗掉。 |
| 香蕉面膜二 | 干皮肤 | 香蕉 1 根捣成半糊，加橄榄油 3 勺调匀。敷脸时避开眼睛和嘴唇周围，15 分钟后温水洗掉。可以用蜜桃代替香蕉。香蕉剥皮后会变黑，做好别放太久。 |

## 9 条注意

书里列的不适合吃香蕉的情况：[^1]

1. 有风湿关节痛（痹证）的人忌吃。
2. 开车的人别空腹吃香蕉：血钾一下升高，会手脚发麻、犯困、心律不齐，容易出事故。
3. 土豆和香蕉别一起吃（书里说会长雀斑）。
4. 香蕉别放冰箱。
5. 香蕉性寒，脾胃虚寒的人少吃，容易肚子疼、拉肚子。
6. 胃痛、拉肚子的人少吃；胃酸多的人最好不吃。
7. 吃太多会伤肠胃。
8. 急性肾炎、慢性肾炎、肾功能不好的人不能吃。
9. 糖尿病人要控制量。
