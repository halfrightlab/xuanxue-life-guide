# 阴阳

> 书里几乎每个道理都落在"阴阳"两个字上：明和暗、动和静、向外和向内、真和假。阴阳是相对的，没有绝对的好坏，讲究的是平衡；作者说"离开了阴阳，就不是易经"。


## 一句话

一阴一阳之谓道。事物都有两面，两面平衡才顺；一味偏向任何一边，都不符合天道。[^1]

## 常见的对应

| 阳 | 阴 |
|---|---|
| 明、亮、热 | 暗、冷 |
| 动、向外、做事 | 静、向内、学习[^2] |
| 真的东西（真花） | 假的东西（假花）[^3] |
| 看别人的优点（升阳） | 盯着别人的缺点（收阴）[^4] |
| 表扬，带着生发 | 批评，带着收敛和毁灭[^5] |
| 东、南（阳气从东到南越来越旺） | 西、北（阴气从西到北越来越重）[^6] |

## 三个要点

1. **阴阳是相对的**：同一个东西，跟这个比是阳，跟那个比可能就是阴。[^7]
2. **阴阳互根**：阴里有阳，阳里有阴，走到极点就转向另一面——比如九宫里阴气从离9（最热的南方）就开始生出来。[^8]
3. **要平衡，不要走极端**：修行修得一味软弱、一味吃苦，就不符合阴阳；风水上一个地方能量过高或过低，也都会出问题。[^9]

## 用在日常

- 看人：总看优点是在给自己"升阳"，总盯缺点是在"收阴"。[^4]
- 带孩子、对伴侣：多表扬、少数落，不是看不到缺点，而是选择阳的一面。[^5]
- 判断一件事：先问它符不符合阴阳之道，见[转念的几个办法](../07-修心/02-转念的几个办法.md)。[^10]
