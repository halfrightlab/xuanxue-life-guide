# 高低和水：砂水平衡

> 入门口诀是"1234 喜砂，6789 喜水"：编号小的方位要加高，编号大的方位要降低，5 是平衡点。但这只是第一步，后面还要看五行、具体东西和住的人。


## 什么是"砂"，什么是"水"

这里的"砂"不只是沙子，"水"也不只是真的水。作者把东西分成两类：[^1]

| 类别 | 意思 | 书里举的例子 |
|---|---|---|
| 砂 | 高的、往上的、大的、像火的，能**提高**能量 | 大树、山、柜子、厨房、电器、红色东西、佛像 |
| 水 | 低的、往下的、凹的、像水的，能**降低**能量 | 江河湖海、水池、鱼缸、下水道、浴室厕所 |
| 没有水也算水 | 低、空、会流动的地方 | 坑、凹地、道路、窗、走廊、楼梯、通风口、黑色东西 |

## 口诀：1234 喜砂，6789 喜水

九宫编号里，**5 是平衡数**。作者的说法是：[^2]

- **1、2、3、4**（北、西南、东、东南）能量偏低，加高点好，所以喜砂。
- **6、7、8、9**（西北、西、东北、南）能量偏高，降低点好，所以喜水。

## 先看哪个，后看哪个

有学员听完口诀，以为风水只看能量、不看五行。老师纠正说，顺序是：[^3]

1. **优先看能量平衡**；
2. **其次也要看五行生克**；
3. **最后按家里人的情况灵活调整**。

所以口诀是入门，不是全部。

## 三个最容易用错的地方

| 想当然的说法 | 作者怎么说 |
|---|---|
| 北方（坎1）属水，那就放水 | 有的门派这么说。作者选的是另一派：1 本来就低，再放水更低，所以坎1**不放水**。[^4] |
| 东方（震3）属木，水生木，放水更好 | 五行上说得通，但作者认为水会把 3 拉得更低，弊大于利。一幅瀑布画挂在震3，他也是这么劝的。[^5] |
| 南方（离9）高，就一律放水 | 作者家里离9放过水，后来撤了：脾气急、火气大的人，那里放水对心脏不友好。[^6]用水不合适的，可以放**不开花的草本植物**，比如绿萝，但别让它长出花盆。[^7] |

## 别用"克"来凑平衡

有读者在北方的厕所里放了黄水晶，想用"土克水"来平衡。作者说：我不提倡去克九宫的宫位。土克水，伤的就是北方这一宫。[^8]

| 宫位五行 | 作者提醒避开 |
|---|---|
| 兑7、乾6（金） | 火克金 |
| 震3、巽4（木） | 金克木 |
| 坤2、艮8、中5（土） | 木克土 |
| 坎1（水） | 土克水 |

## 同一件东西，可能既是水又是火

- **饮水机**：里面一直有水，又通电，作者说"有水也有火"。红色外壳还会多加一份火，所以黑色和红色饮水机不一样。[^9]
- **洗衣机、冰箱**：作者说这两样"很有争议"，要看实际情况，不能一句"通电就是火"定死。[^10]

## 一个具体例子：东北放两碗水

> [!TIP]
> **厨房太小，放两碗水**
>
> 课堂上老师讲：东北（艮8）本来就高，再放高能量的东西会更失衡。处理办法是先把高能量的东西搬走，再放两盆水降一降。[^11]
>
> 有个学员出差时没头皮屑、回家就有，学过之后发现东北是厨房。厨房太小，放两盆水会超出这一格，他就放了两碗水，后来头皮屑没了。老师补了一句：他的情况比较轻。地方够的话，可以用稍大一点的容器，"二三十厘米的吧"。


书里没说这二三十厘米是量直径还是量高度，也没规定水放多少、多久换。

## 舒服比"做成标本"重要

讲窗帘颜色时，作者说可以每个方位配不同颜色，但更建议用米色、棕色、咖啡色这类土色统一，**舒服、好看、方便**比把家做成"风水标本"重要。[^12]
