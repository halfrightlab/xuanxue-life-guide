# 先找准方向：大太极和小太极

> 看风水第一步是找准真实的东南西北，按房子的实际比例画九宫。整套房子是一个"大太极"，每个房间又是一个"小太极"，两层都要看。方向一错，后面全错。


## 书里的图是"南上北下"

现在的地图和房本户型图大多是**上北下南**。这本书的图反过来，是**南在上、北在下、东在左、西在右**。看书里的图、画自己家的图时，先把方向转对。

| 东边一列 | 中间一列 | 西边一列 |
|---|---|---|
| 东南 · 巽4 · <span class="wx-wood">木</span> | 正南 · 离9 · <span class="wx-fire">火</span> | 西南 · 坤2 · <span class="wx-earth">土</span> |
| 正东 · 震3 · <span class="wx-wood">木</span> | 正中 · 中5 · <span class="wx-earth">土</span> | 正西 · 兑7 · <span class="wx-metal">金</span> |
| 东北 · 艮8 · <span class="wx-earth">土</span> | 正北 · 坎1 · <span class="wx-water">水</span> | 西北 · 乾6 · <span class="wx-metal">金</span> |

小窍门：竖着读三列，就是"438、951、276"。作者自己就是这样写的。[^1]

## 画九宫的四步

第267章给了具体做法：[^2]

1. **测方向。**用指南针贴着墙校准。现在的房子多是钢筋混凝土，会干扰指南针，所以每面墙都要测一下，屋里屋外对一对。[^3]
2. **按比例画图。**可以数地砖算长宽，也可以照房本上的户型图描。房本图是上北下南，描完记得倒过来。
3. **三等分。**东西方向分三份，南北方向分三份，就成了九格。九宫**不一定是正方形**，长方形的房子就画长方形的九宫。[^4]
4. **看东西落在哪一格。**

作者没给"误差多少度可以接受"之类的精确标准，他强调的是：**多测几个地方，互相对一对**。

## 大太极和小太极

| 看的范围 | 叫什么 | 例子 |
|---|---|---|
| 整套房子 | 大太极 | 客厅在全屋的北边 |
| 一个房间 | 小太极 | 鱼缸在客厅的北边 |
| 一个院子 | 也可以单独画九宫 | 院子里的果树、猪圈算不算在里面，会影响结果 |
| 一件东西 | 一物一太极 | 一幅画本身也能分九宫，见[字画和摆件](10-字画和摆件.md) |

所以一个鱼缸可能同时落在"全屋的北边"和"客厅的北边"，作者叫它"**坎1的坎1**"，问题叠了两层。[^5]

## 门、床、座位：位置和朝向都要看

有人问：大门开在兑7（正西），却面朝坤2（西南），算哪个门？作者答：按位置，人来回走会带动兑宫；按朝向，也受坤宫影响。**两样都算，不是二选一。**[^6]

床也一样。床摆在坤2和离9之间、头朝东睡，还会受到东边巽4的影响。[^6]座位主要看背后朝哪边。

书里没有给"跨两格时各占几成"的算法，所以不要只凭床的一个角落下结论。

## 一个方向搞错的例子

> [!TIP]
> **双胞胎换了学习位，成绩反而变差**
>
> 一位妈妈按自己画的图，把孩子的床和书桌从"凶位"挪到"吉位"，结果两个孩子成绩都往下走。作者先从方位、命理、吉位里有没有煞几方面找原因，后来才发现：她以为的南其实是西，整张图要**顺时针转 90 度**。真正的门在艮8，原来的位置本来是生气（吉），挪去的地方反而是五鬼（凶）。[^7]妈妈已经把位置搬了回去。


这个例子要说的是：**先把方向测准**。方向错了，后面算得再仔细也白算。

## 书里没给的东西

- 不规则户型怎么画外框，没有统一算法。作者在一张斜房图外补画过一个外框再三等分，但只是那一个例子。[^8]
- 全包阳台、露台算不算进去，没有统一规则。
- 不能光看一张照片就定方向。作者说照片很难辨认方向。[^9]
