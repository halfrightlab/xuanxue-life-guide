# 卧室和床

> 床放哪、头朝哪，要一起看卧室门、自己的命宫、属相和周围的东西。书里列了一大堆互相打架的"睡向说法"，作者的意思是：没有人人都适用的唯一方向。


## 头朝哪睡？说法太多

BUN 问作者头该朝哪睡，作者把四个方向的说法挨个说了一遍：[^1]

- 顺着地球磁力线，头朝南北好；
- 也有人说头朝北，血液里的铁受磁场影响，不好；
- 东方是太阳升起的方向，头一定要朝东；
- "活人睡东西，死人睡南北"；
- 有个词叫"归西"，所以千万别朝西；
- 还有人说朝北为阴、朝西不吉、朝东伤身，朝南最好。

BUN 听完以为作者在蒙他。这些说法本来就**互相矛盾**，作者只是把它们摆出来。

最后作者是按 BUN 的命宫给的建议：在那个房间里，**头朝西**对他最有利。BUN 问回家后是不是也朝西，作者说：只要是"西四命宫开门"的卧室，就可以。[^2]下一章他又解释：BUN 主要是"五鬼"多，所以先看卧室门，再看属相和喜用，重点帮他避开五鬼位。[^3]

所以这是 BUN 一个人的答案，**不是人人都朝西睡**。

## 床在哪一格，门和人配不配

床本身可能跨两格，床头朝向又会牵扯别的方向，床越宽牵扯越多。[^4]

还要分两层看：**人和门**配不配，**门和床**配不配。

> [!TIP]
> **宿舍的床：门是好门，床位不好**
>
> 一个孩子是震3命，宿舍开离9门，3 和 9 配成"生气"，是好门。但他睡在乾6和兑7之间，头朝坤2：和门一配，分别是 69 绝命、79 五鬼、29 六煞。作者解释：五鬼让脑子停不下来，六煞让人心思细、负面情绪重，放一起就是"脑子不停地想负面的事"。[^5]


## 床的周围别有这些

作者在第469章列过让人"心神不宁"的东西：[^6]

| 位置 | 别有什么 |
|---|---|
| 头顶 | 床上方的吊灯、横梁、床头挂的空调 |
| 床头 | 重重的照片 |
| 对着床 | 镜子、电视电脑的屏幕 |
| 屋里 | 刀剑等利器 |

- 横梁压床，作者说化解很简单：**把床挪个位置**。[^7]
- 一整面墙的镜子对着床，作者建议从顶到底遮住。[^8]
- 有柜子的尖角对着床中间，也要看看。[^9]

## 卧室里别放"招阴"的东西

作者说卧室是睡觉的地方，晚上人静静躺着，所以容易"招阴"的东西别放在卧室：[^10]

- 黑白照片
- 空花瓶，尤其是又高又深、口小、不透明的[^11]
- 奇形怪状的玩偶
- 石头，古玩（尤其是出土的）
- 太多植物，尤其是爬墙的

另外，南北特别长的"面条房"，阳光照不进深处，作者也说容易阴气重。

## 别人睡过你的床

作者说"不要让别人睡自己的床"。[^12]真被睡过了，没什么大问题的话，把床单被罩洗一洗，拿到太阳下晒一晒，也可以用香薰。[^10]
