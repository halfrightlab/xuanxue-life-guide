# 魂魄和梦

> 书里借《黄帝内经》讲魂魄：魂管心灵智慧，魄管身体机能，两样都要养。怎么看自己魂魄全不全？睡前告诉自己几点醒，不用闹钟就能醒。梦大多是胡思乱想，凌晨四五点后那种特别清楚、像真的一样的梦，才可能有提示。


## 魂和魄

| | 魂 | 魄 |
|---|---|---|
| 管什么 | 心灵、智慧 | 身体机能、本能反应 |
| 阴阳 | 动，属阳 | 静，属阴 |
| 藏在哪（《黄帝内经》） | 肝藏魂 | 肺藏魄 |
| 受伤了 | 反应迟钝，像行尸走肉 | 身体器官运转出问题 |
| 怎么养 | 精神需求 | 吃好穿好 |

[^1]

富裕了，魂得不到滋养也会出事。[^2] 道家说人有三魂七魄。[^3]

**一个简单的检查**：醒着时清醒、不迷糊、有灵感；睡着时也"清醒"——睡前告诉自己几点起，不用闹钟就能准时醒。[^2]

注意力就是神魂：走神就是"魂飞了"。[^4] 最容易扰乱神魂的是情绪。[^5]

## 鬼

- 书里说，"鬼"大多是人对未知的恐惧；鬼魂人人都有，人还多一个能作用于实物的身体，没什么好怕的。[^6]
- 天天想着鬼要吃我，就常遇到邪乎事——注意力就是生命力。[^7]
- 满脑子都是鬼的人，不要做任何尝试，只修脾气。[^8]

## 梦

- **怎么分辨**：早上四五点以后做的、记得特别清楚、像真的一样的梦，一般有暗示；其余多是胡思乱想。[^9]
- 庄子说"古之真人，其寝不梦"：修得好的人很少做梦。[^10]
- 睡得不踏实、多梦，书里也会先查床位有没有在五鬼位，见[八颗星](../04-名字和数字/10-八颗星.md)。[^11]
