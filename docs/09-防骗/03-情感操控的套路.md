# 情感操控的套路

> 番外里作者把一个粉丝对自己用过的话术一条条记在备忘录里，一共十几条：真诚示好、退而求其次、"你是唯一"、忽冷忽热、贬低打压、示弱卖惨……被人牵着走时，可以对照看看。


番外"修行修自己"里，一个叫陈锋的粉丝一步步让作者（书里叫小怡）破了"不接个案、不轻易起卦"的底线。作者事后复盘，把对方的话术记成了"套路清单"。[^1]

## 套路清单

| 套路 | 是什么样子 |
|---|---|
| 真诚是必杀技 | 先刷礼物，再"良心发现"主动坦白本来的打算——人家都掏出真心了，你反而不好意思拒绝。[^2] |
| 退而求其次 | 你拒绝了大要求，他就提个小的：不看户型了，就看看财运；不帮忙了，就吃个饭。[^3] |
| 人设 | 豪气霸总、落魄才子，两天就能演完。[^4] |
| "你是唯一" | "你是我的例外、唯一、独一无二"——最容易让人自己脑补。[^4] |
| 话说一半 | 模棱两可，好像什么都说了，又好像什么都没说，方便不负责。[^4] |
| 适当打压 | 一味仰望没前途，时不时打压你一下。[^4] |
| 画饼 | "等我有能力了，脏活我帮你干。"[^5] |
| 忽冷忽热 | 热一会儿冷一会儿，近一会儿远一会儿，仰望一会儿打压一会儿。[^6] |
| 情绪拉扯 | 把你气个半死，又瞬间让你消气——极限拉扯最容易上头。[^7] |
| 先压后软 | 先在气势上压住你，等你底气不足时再示弱卖惨。[^8] |
| 贬低 | "你有 120 斤那么胖吗？我也是勉为其难。"贬低和打压最容易形成精神控制。[^9] |
| 镜像效应 | 反复引用、复述你说过的话，让你很快信任他、对他有好感。[^10] |
| 真假掺着说 | 一句话里几分真几分假，很难反驳。[^11] |

## 怎么不被牵着走

- **发现自己的底线在一退再退**，就要停：从不接个案，到起卦，再到想借外力帮他——作者后来才看清自己是怎么一步步被带偏的。[^12]
- **心和脑不在一条线上时要警惕**：理智知道不该，心里却于心不忍。[^8]
- **提醒过对方还不改，就停**：不管同性还是异性，提醒后对方依然越界，就不是你能帮的人，继续聊只会伤到自己和家人。[^13]
- **陌生人搭讪先冷处理**：发"在吗""你好"、气息不对的，不回或少回，保持距离。[^8]
- **看结果，不看话**：不预判，让事实和时间来验证。[^11]
- **看不透时换个人来看**：假设这事发生在别人身上，你会怎么评价？[^14]
