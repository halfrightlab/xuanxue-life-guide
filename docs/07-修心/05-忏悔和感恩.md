# 忏悔和感恩

> 书里说，把憋在身体里的那口气连根拔掉，最管用的两样是忏悔和感恩。忏悔是"跟谁生的气就向谁认错"，感恩是只跟自己的起心动念有关，不是发红包。两样都得走心，嘴上说没用。


把气连根拔起的办法：忏悔和感恩，作者称之为宇宙中最纯粹的力量。[^1]

## 忏悔：跟谁生的气，就向谁认错

**大忏悔的做法**：[^2]

1. 回想当初是跟谁生气、怨谁恨谁，才招来了这个病或这件事。
2. 真心向那个人忏悔、认自己的不是（当面或在心里都行）。
3. 真忏悔会有反应：呕吐、排泄、放屁、打嗝等，这是在往外排。
4. 然后大笑，把阳气提起来。
5. 以后照本分踏实做人：任劳任怨，孝养父母，友爱兄妹，照顾家人。

**排毒反应**：走心忏悔时想吐就吐，不想吐不用刻意。吐出来的多是黏痰，可能持续几天到几个月，吐干净就自然停了。[^3]

**哪里疼找谁**：头颈不舒服，想想和父母、师长、领导的气；腰胯不舒服，想想和爱人、同事的气；腿脚不舒服，想想和孩子的气。[^1]

## 感恩：会感恩，才会快乐

- 修行的根本就两点：感恩，多看事情好的一面。感恩只跟自己的起心动念有关，不是发红包。[^4]
- 感恩运气顺，抱怨德不存；贵人愿意帮的，是有感恩之心、能实实在在提供价值的人。[^5]
- 常怀感恩可以化解坏脾气。[^6]
- 对一段经历只有感恩没有愤恨，它就会带来智慧。[^7]

## 必须走心

一位读者念象数没效果，后来发现是"嘴在念、心没念"。念经、忏悔、感恩都一样：嘴上说对不起，心里没到，淤堵就排不出来。[^8]

> [!TIP]
> **内修时觉得不对劲**
>
> 念象数、读经、看书或视频时，如果发凉、心里不舒服、头晕、发酸、像被腐蚀，先停下来，用感恩提升正气，用忏悔排出毒气。[^9]
