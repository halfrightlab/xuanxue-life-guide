# 自省不是自责

> "修行修自己"常被误会成"什么都是我的错"。作者说：自省是找自己的"贪"在哪，然后问"我能做点什么让事情更好"；一味骂自己、逼自己，其实也是向外求。


## 自省是什么，不是什么

| 是自省 | 不是自省 |
|---|---|
| 找自己的"贪"在哪里——人生大部分痛苦都能从贪上找到答案[^1] | 总觉得"没赚够钱、对不起家人"，逼自己少睡多干[^1] |
| 自己愿意提升时向内看[^2] | 被别人逼着反省[^2] |
| 对方的问题对方修，我只看"我能做什么让事情更好"[^3] | 把所有错都揽到自己身上 |
| 客观地问"我差在哪儿"[^4] | 骂自己"没慧根"——这是向内攻击；骂别人"骗子"——这是向外攻击[^4] |

## 也不是什么都要忍

- 自己也是众生之一，纵容别人作恶，是消业还是造业？[^5]
- 善良可以是底色，但不能成为枷锁：退一步能让心静就退，退了对方变本加厉就不退。[^5]
- 不想无偿帮就公平谈交易，别心里做交易、嘴上说无私，两边都难受。[^3]

## 一个检查

做完一件事，看看自己的状态：心情是不是越来越愉悦，身体是不是越来越好，人际是不是越来越和谐。越修越苦、越修越憋屈，方向就错了。见[怎么判断修得对不对](07-怎么判断修得对不对.md)。[^5]
