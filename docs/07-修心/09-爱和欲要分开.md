# 爱和欲要分开

> 番外里吉月姐姐对作者说：爱有很多种——友情、亲情、战友情……男女之情只是其中一种，是"欲"。把所有感情都看成男女之情，就看不懂人和人之间更大的爱，也更容易被人用感情拿捏。


## 爱是一条彩色的光谱

- 爱分很多种：友情、爱情、亲情、同窗情、战友情……大爱没有私情；男女之情是小爱，是欲。[^1]
- 每种爱都有自己的颜色，连起来像一条光谱；把所有感情都看成男女之情，光谱就只剩下红色。[^2]
- 现在出轨多，书里认为是很多人分不清爱和欲，只想从外面抓东西满足私欲。[^2]

## 小我和大我

| 小我 | 大我 |
|---|---|
| 依附肉身，在意私利 | 没有分别心，和万物一体 |
| 凡事想"我高兴、我想要、我吃亏了" | 能旁观自己的情绪，不被情绪控制 |
| 总想从外面索取认同 | 内心安定，外在包容，不强求、不攀缘 |

[^3]

## 落到日子里

- 神性本自具足，不用靠外面的人或物来填欲望——那条路没有尽头；心里缺什么，要从内在修圆满。[^1]
- 爱要落地：命都可以给你，不如把家收拾干净、一日三餐做好。[^4]
- 帮人时不必有性别上的分别心；但对方动了情欲、提醒了还不改，就该停，否则伤的是自己的家人。[^5]
