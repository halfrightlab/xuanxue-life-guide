# 洗心养神功

> 作者最常推荐的静心方法，简单到小孩都会：把注意力放到眼前的颜色、声音、气味、味道和触感上。想太多、心散、总想从外面找刺激时就用它。


## 为什么有用

作者说：注意力就是生命力，走神就是"神"跑了。把注意力收回到眼前的东西上，就是把"神儿"找回来。[^1]

## 简易版：只练眼睛

第47章作者教一个有洁癖、不敢出门的女孩用的就是这个：[^2]

1. 出门散步。
2. 一边走，一边把所有注意力放在依次看到的东西上。
3. 只数**颜色**（红、黄、灰……），或只数**形状**（三角形、正方形……），选一种就行。
4. 像小婴儿一样，好奇地看这个世界。

想得太多、闷在屋里的人，再加上：卧室常拉开窗帘、多通风，随时抬头看看窗外。[^3]

## 完整版：六个方面

番外里作者写了完整版，从眼、耳、鼻、舌、身、意六个方面"洗"和"养"，随时随地都能做：[^4]

| 方面 | 怎么做 |
|---|---|
| 眼 | 看不同的颜色、不同的形状 |
| 耳 | 听各种不同的声音 |
| 鼻 | 闻能闻到的各种细腻气味 |
| 舌 | 吃饭、喝水时放慢，仔细品尝入口的东西 |
| 身 | 感受触觉：手上的触感、走路时脚踩地的感觉、风吹过皮肤 |
| 意 | 打坐或站桩，让身心静下来，如实看着自己的念头 |

佛家持咒时常常同时捻珠，也是这个道理——用手上的触感把注意力收回来。[^4]

> [!NOTE]
> 姿势只是辅助，关键是随时觉察自己的念头。一边做一边算计能得到什么好处，就没用了。[^4]


## 还能用在哪

- **学了相面、风水以后，看谁都忍不住分析**：熟练后要有意识地停下脑子，看到什么就只是看到；停不下来就多练这个。[^5]
- **身上疼**：先把注意力放到外面的实物上一两分钟，再回来感知疼痛，反复几次。[^6]
- **开智慧、头脑不清**：作者列的第一条办法就是洗心养神。[^7]
