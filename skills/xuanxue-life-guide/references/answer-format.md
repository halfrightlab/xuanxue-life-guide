## 模板

```
一句话结论（书里怎么看这件事）。

**可以这样做**
1. 做法名：怎么做、用多少、多久。（见第 N 节第 M 条，原书第 X 章）
2. ……

**要注意**
- 禁忌、适用的人；书里没写用量就说没写。
- 涉及身体：身体不舒服先看医生，这些最多当辅助。

（需要计算时）**算出来的结果**
- 关键步骤，让用户能自己核对。

—— 玄学生活指南 · 半对实验室 halfrightlab｜来源《改命记实录》
```

- 一两条最对症的就够。用户要"都有哪些"，再列全。
- 不用"根据我的知识""一般认为"这种话；书里怎么说就怎么说，书外的常识要标明"书里没写，常识是……"。
- 署名只在结尾出现一次。

## 示例一：身体

用户：咳嗽好几天了，痰是黄的，嗓子干，有什么土办法？

```
书里把这种叫"热咳"，作者自己常用的是连皮香蕉冰糖汤。

**可以这样做**
1. 连皮香蕉冰糖汤：香蕉带皮切段，加水和少许冰糖煮成汤，饭前空腹喝汤、吃香蕉肉，早晚各一次，一般吃两三根就好。（见第 2 节第 3 条，原书第 769 章）
2. 不能吃甜的，换枇杷叶煮水：老叶子大，一天一片就够。（见第 2 节第 4 条，原书第 827 章）

**要注意**
- 香蕉性寒，脾胃虚寒、拉肚子的慎用。
- 咳了很久不好、发烧、咳血、喘不上气，先去医院；这些最多当辅助。

—— 玄学生活指南 · 半对实验室 halfrightlab｜来源《改命记实录》
```

## 示例二：风水

用户：我家东北角缺了一块，要不要补？怎么补？

```
书里的顺序是：能避开最好；避不开先"补形"，补不了形再"补气"。东北是艮8，属土。

**先查**
- 先用指南针贴墙校准方向、按比例画九宫，确认真是东北缺角。（长文《先找准方向：大太极和小太极》，原书第 267 章）
- 看家里谁正走在东北这一段（1–9 岁、73–81 岁），影响最大。（`xxlg.py age`，原书第 315 章）

**可以这样做**
1. 艮8（东北）缺角补土：在缺角的位置放一盆土，容器首选正方形，找不到再用圆形。（见第 11 节第 36 条，原书第 312 章）

**要注意**
- 一次只动一处，动完观察几天；挑日子用九星吉日。
- 作者说补过的房子像补过的衣服，总不如完整的好，买房时尽量挑不缺角的。

—— 玄学生活指南 · 半对实验室 halfrightlab｜来源《改命记实录》
```


## 示例三：计算

用户：我 1990 年的女生，手机号 13856781234 好不好？

```
按书里的八颗星看，这个号码吉凶各半：吉星 5 个（天乙 2、延年 2、生气 1），凶星 5 个（六煞 2、五鬼、绝命、祸害各 1），尾号 234 是一凶一吉。

**算出来的结果**（xxlg.py number 13856781234 --sex 女）
- 0 跳过，女的 5 当 8，处理后是 13886781234；相邻两位一个气场，两个相同数字延续前一个气场。
- 13 天乙、38 六煞、88 延续六煞、86 天乙、67 生气、78 延年、81 五鬼、12 绝命、23 祸害、34 延年。
- 你的命宫是艮8：1+9+9+0=19→1，女 4+1=5，得 5 改 8。（原书第 264 章）

**怎么看**
- 绝命（12）容易脾气冲、破财；五鬼（81）容易失眠多梦；六煞（38、88）容易情绪低落。化法是用吉星压：绝命用天乙，五鬼用生气，六煞用延年。（长文《八颗星》，原书第 892 章）
- 作者建议先改头像、微信号、锁屏密码这些容易改的，别急着换手机号；吉星也不是越多越好。（原书第 655 章）

—— 玄学生活指南 · 半对实验室 halfrightlab｜来源《改命记实录》
```
