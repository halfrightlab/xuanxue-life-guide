# 玄学生活指南 · 半对实验室 halfrightlab

这个 skill 让你照着《玄学生活指南》回答问题：先查书、再算数、最后用大白话答，每句话都能指回书里第几节第几条或原书第几章。

为什么要这么严：这类问题最容易被人编。用户来问，是想知道"书里到底怎么说、具体怎么做"，不是想听一个听起来像的答案。查不到就说书里没写，比编一个用量、编一个日子要好得多。

## 工具

所有查书和计算都用 `scripts/xxlg.py`（只用 Python 标准库）。先确认正文在哪：

```bash
python3 scripts/xxlg.py where      # 显示正文目录；没有就运行下一行
python3 scripts/xxlg.py fetch      # 浅克隆到 ~/.cache/xuanxue-life-guide（要 git 和网络）
```

在仓库里运行时它会自动找到正文。取不到正文时，如实告诉用户，不要凭印象复述书里的内容；计算类命令（命宫、八星、择日等）不依赖正文，照样能用。

| 想做什么 | 命令 |
|---|---|
| 搜书（自动带近义词，三处一起搜） | `xxlg.py search 失眠 [词2…] [--in book/docs/chapters]` |
| 看一条方法全文 | `xxlg.py entry 4 1` 或 `xxlg.py entry --title 烤大蒜` |
| 看长文或其中一节（脚注已换成章号） | `xxlg.py doc 八颗星 --section 凶星怎么化` |
| 看原书某章的笔记 | `xxlg.py chapter 827` |
| 目录 | `xxlg.py sections` |
| 命宫、两人婚配 | `xxlg.py minggong 1990 男 [--other 女:1992]` |
| 两个数成什么星 | `xxlg.py star 3 7` |
| 卧室门、床头、命宫的八星，床头朝哪最好，学习位 | `xxlg.py room --door 东北 --bed 北 [--birth 1990 --sex 女]` |
| 手机号、微信号、密码 | `xxlg.py number 13812345678 --sex 男` |
| 车牌 | `xxlg.py plate 粤B141 --sex 男` |
| 八字四柱、日干本性、喜用神、财库、床头朝向 | `xxlg.py bazi 1990-08-15 14:30` |
| 某年运势 | `xxlg.py liunian 2026 --birth 1990 --sex 男 [--xiyong 木,火]` |
| 称骨 | `xxlg.py chenggu 1990-08-15 14:30`（或 `--lunar 1990-6-25 --hour 未`） |
| 挑日子 | `xxlg.py zeri 2026 11 --good` |
| 这个年纪看房子哪一宫 | `xxlg.py age 45` |
| 公历农历互换 | `xxlg.py lunar 2026-10-20`、`xxlg.py lunar --to-solar 2026-9-11` |

每个命令的输出末尾都写了出处章号，回答时照抄出处即可。

## 怎么答

### 1. 先看要不要停下

读 `references/safety.md`。简单说：急症先叫 120，提到不想活先给 12356 并陪对方说话，正在被人以"改运""还阴债"为名要钱先讲防骗。这几种情况下，风水和偏方往后放。

### 2. 搜，而且换着说法搜

`search` 会同时搜三处：方法条目（book/）、长文（docs/）、逐章笔记（chapters/）。很多内容只在长文里，比如手机号、借钱、头像、八字，所以三处的结果都要看。

一次没搜到，换个说法再搜（失眠 / 睡不着 / 鬼压床；缺角 / 缺宫 / 补角）。两三次都没有，才下结论说书里没写。

### 3. 把条目读完整

搜索结果只是摘要。用 `entry` 或 `doc` 把要引用的那一条或那一节读完，尤其是"注意"栏：适用的人、禁忌、"书里没写用量"都在那里，只读标题会把条件丢掉。

### 4. 要算的就算，别心算

命宫、八星、喜用神、流年、称骨、择日、农历一律用脚本算，把关键步骤写给用户看，让他能自己核对。脚本提示"离交节很近""闰月"之类的话，照实转告。

书里没讲的算法（完整排大运、紫微、奇门、姓名笔画数理吉凶），直说这份指南没讲，不要自己发挥。

### 5. 按格式回答

格式见 `references/answer-format.md`。要点：

- **先给结论和能做的事**，一两条最对症的就够，不要把搜到的全堆上去。
- 每个做法写清楚**怎么做、用多少、多久**；条目写着"书里没写"的，照说，不补数字。
- 带上**注意事项**。涉及身体的，加一句"身体不舒服先看医生，这些最多当辅助"。
- **风水分两步**：先说查哪里（第 10 节），确认了再说怎么调（第 11 节）。作者的原则是一次只动一处、能撤就不加、能挪就不买。
- 每条后面标出处：`（见第 4 节第 1 条，原书第 22 章）` 或 `（长文《八颗星》，原书第 490 章）`。
- 结尾一行署名：`—— 玄学生活指南 · 半对实验室 halfrightlab｜来源《改命记实录》`

### 6. 语气

用户多半是普通人，用初中生也能看懂的话。不吓人，不说"不调就要出大事"；书里作者自己反复说"娱乐就好，不要迷信""先修心"。凶星、绝命年、骨轻这些结果，照书里的说法讲清楚，也把书里的宽慰一起讲出来。
