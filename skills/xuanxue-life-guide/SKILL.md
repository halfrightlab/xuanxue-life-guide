# 玄学生活指南：查了再答

## 这个 skill 干什么

有人问一件过日子的事书里怎么说、该怎么做，先去《玄学生活指南》里把相关条目查出来，再照条目回答。

**没查到就别答。** 回答里的每个做法、用量、数字（象数、方位、日子）都要能指回某一条正文。指不回去，就直说书里没写；可以补一句常识，但要标明那是常识，不是书里的内容。不要凭记忆编象数数字、编用量、编章节号。

## 第 0 步：先看要不要马上停下

- **急症或重病**（胸痛、呼吸困难、大出血、高烧不退、中毒、昏迷、孩子精神很差）：先让对方打 120 或去医院，别先讲偏方。
- **提到自杀念头、活不下去**：先给全国心理援助热线 12356，陪对方把话说完，不讲风水和"业力"。
- **对方正被人以"改运""化灾""还阴债"为名要钱**：先指长文 docs/09-防骗/ 里的条目。
- 其余情况，照下面的步骤走。

## 第 1 步：把正文拿到手

**本地**：当前目录或上级目录里有 `README.md` 和 `book/01-睡不好.md`，就是本地模式，直接读。

**远程**：没有就浅克隆一次：

```bash
git clone --depth 1 https://github.com/halfrightlab/xuanxue-life-guide.git "${TMPDIR:-/tmp}/xxlg"
```

不能用 git 时，按文件取：

```bash
curl -fsSL "https://raw.githubusercontent.com/halfrightlab/xuanxue-life-guide/main/book/02-咳嗽和嗓子.md"
```

都取不到，就如实告诉用户取不到正文，不要凭印象复述。

## 第 2 步：定位到节

读 `README.md` 里「这份指南想回答的问题」那张表。一行一节，写了这一节回答什么问题，带着 `book/` 或 `docs/` 下的路径。挑 1 到 3 个最对得上的。

- `book/NN-节名.md`：短条目，一条一个办法。
- `docs/NN-类别/NN-标题.md`：专题长文，把一件事讲透。象数的数字清单、择日规则、八颗星对照表都在长文里。
- `chapters/改命记实录/`：原书每章的白话笔记，用来核对出处。

## 第 3 步：把条目捞出来

节文件不小，别整篇读，按关键词捞：

```bash
grep -rn '^### ' book/ | grep -E '咳嗽|痰'              # 看有哪些条目标题
grep -rn -A7 '^### .*牙' book/03-牙和口腔.md            # 带上整条
sed -n '/^### 5\. /,/^### 6\. /p' book/02-咳嗽和嗓子.md   # 按条号抽一整条
grep -rln '缺角' docs/                                  # 找长文
```

**抽出来的条目要整条读完**，尤其是「注意」栏：适用的人、禁忌、"书里没写用量"都在那里。

每条的格式：

```
### N. 标题
- 用来：治什么、管什么
- 怎么做：具体做法和用量
- 注意：禁忌、适用范围；"书里没写"表示原书没给
- 依据：作者亲测 / 读者反馈 / 师父所传 / 资料摘录 / 书中说法
- 来源：《改命记实录》第N章《章名》
```

## 第 4 步：回答

1. **先给能做的**：一两条最对症的办法，照条目写清怎么做、用多少；条目写"书里没写"的，照说，不补。
2. **再给要注意的**：把「注意」栏的禁忌带上。涉及身体的，加一句"不舒服先看医生，这些最多当辅助"。
3. **风水问题分两步**：先说该查哪里（第 10 节"先排查"），确认了再说怎么调（第 11 节）。作者的原则是先确认问题、一次只动一处、能撤就不加。
4. **注明出处**：每条后面写「见第 N 节第 M 条」，需要时补原书第几章。
5. **依据要照实说**：「依据」是这条在书里怎么来的，不是科学证据。别把"书中说法"说成"有效""经过验证"。

## 不要做的事

- 不替书补用量、补数字、补日子。择日要具体日期的，用 `tools/jiri.py` 现算，或者照长文里的规则一步步算给用户看。
- 不吓人。不说"不调就要出大事"这类话；书里作者自己也反复说"娱乐就好，不要迷信"。
- 不推荐收费的法事、请神、买开光物件。用户问到，指去防骗那几篇长文。
