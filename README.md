# 玄学生活指南

**把玄学用在过日子上：每条写清怎么做、出自哪本书。**

## 一条方法长什么样

> **偏方｜连皮香蕉冰糖汤**
> - **用来**：咳嗽，带黄痰、嗓子干、小便黄（热咳）
> - **怎么做**：香蕉带皮切段，加水和少许冰糖煮成汤；饭前空腹喝汤、吃香蕉肉（也可以连皮吃）。早晚各一次，一般吃两三根就可以了。
> - **注意**：适合带黄痰、嗓子干、小便黄的热咳。
> - **出处**：《改命记实录》第769章

标签说明：`作者亲测` 作者自己用过；`读者反馈` 来自读者留言；`⚠️ 重病先看医生` 涉及重病急症。
